# Installation

1. Use a Paper server compatible with this build (see `api-version` in `src/main/resources/plugin.yml`) and the matching Java version.
2. Remove any existing Skript jar from `plugins/`. **Never run Skript and SkriptReloaded together.**
3. Drop `SkriptReloaded-<version>.jar` into `plugins/` and start the server.
4. Optional: install PlaceholderAPI to use the placeholder expressions.

Your existing `plugins/Skript/` folder (config, scripts, variables) is reused as is.
