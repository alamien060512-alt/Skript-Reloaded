# SkriptReloaded Wiki

SkriptReloaded is a fork of [Skript](https://github.com/skriptlang/skript) that adds extra syntax while staying
compatible with existing `.sk` scripts and Skript addons.

- [Guides](Guides.md): command aliases, sidebars, HTTP, PlaceholderAPI
- [Building from Source](Building.md)
